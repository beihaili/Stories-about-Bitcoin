# 第四十三章 这次是我自己接单

北京那天风很大。

平台先弹出一条扣款通知，说李觉上一单到店等待轨迹异常，扣一块二。互助池里编号 003 的单据补上了，但又有人质疑为什么编号 004 可以先用钱后补证明。陈浩在杭州发来一张房间照片，床靠着窗，窗外是一堵墙。母亲问他下个月五号还转不转那笔钱，问完又补一句，风大就别跑太晚。

现实没有因为故事走到最后一章，就突然变得体面。

李觉站在麦当劳门口，外卖服拉链卡了一下。他低头弄了半天，才把拉链拉到胸口。

赵晴在旁边看天气雷达。

“学院路那边别接。”她说，“风口，逆风能把你吹回上辈子。”

李觉笑了一下。

赵晴看他：“你真不打算停一阵？你现在又不是一停就没饭吃。”

李觉没有马上回答。

他确实可以停一阵。小仓位、稿费、工具捐赠和互助池之外的余额，够他不跑几个月。以前他以为有一天自己能离开外卖，就算赢。后来发现，离开当然是选择，但不是唯一的证明。

手机震动。

下单人：中本聪。

备注：`btc block 0`

李觉看着那三个字符，笑意慢慢收住。

第一次看见 block 0 时，他以为那是创世区块，是一个陌生人开的玩笑。后来他知道，block 0 也可以指向比比特币更早的一切，指向哈耶克的纸片，指向咖啡馆里的宣言，指向所有还没被命名的开始。

这一次，它又回来了。

取餐地址是一家普通便利店。送达地址在一栋老小区，楼号清楚，门牌清楚，导航没有打转。李觉甚至怀疑这就是一单普通订单。

没有白光，没有历史街景，也没有谁把他带回某个决定世界的房间。最后一单朴素得过分，像账号终于把所有神秘都撤掉，只留下他每天本来就在做的事。

他骑过去，风从脸侧切过来，像有人一直在提醒他，北京不会配合任何人的终局。

便利店老板把袋子递给他，里面是一份热粥和一盒药。备注写着：放门口就行，别敲太久。

老小区没有电梯。李觉爬到六楼，楼道里有油烟味和潮湿墙皮的味道。他把袋子放到门口，正准备拍照，门忽然开了一条缝。

一个女人探出手来，年纪看不出来，头发随便扎着，手腕上有一道很浅的烫伤疤。

“辛苦。”她说。

屋里桌上放着一台开着机的电脑，屏幕上是黑底白字的终端。旁边有一个铁盒，盒盖半开，里面压着几张纸。最上面那张纸的边角有咖啡渍。

李觉的手停在拍照按钮上。

女人顺着他的目光看了一眼，像想起什么，笑了笑。

“旧东西。”她说，“有些人总要把没说完的话——”

屋里电话响了。

她回头接电话，门半掩着，只剩那半句话停在楼道里。

李觉没有问。

他没有问她是谁，没有问铁盒里的纸从哪来，也没有问中本聪账号是不是她下的单。他甚至没有再看那只铁盒第二眼。

很多问题如果非要一个答案，反而会把它们问小。

手机显示订单完成。

客户评价：⭐⭐⭐⭐⭐

客户留言：继续。

这个“继续”不像命令，也不像奖励。

它更像把选择又推回他手里：你已经看过那么多开始、失败、争吵和收编，接下来还要不要做，没人替你点确认。

李觉站在六楼楼道里，听见电梯井没有电梯的空响，听见外面的风撞在窗户上，听见自己手机里普通订单继续刷新。

他忽然觉得，这就是最接近答案的东西。

不是某个人站出来说我就是中本聪。

也不是系统揭开机制，说你被选中的原因是第一章第几行埋的伏笔。

而是有人继续写代码，有人继续运行节点，有人继续把风险说清楚，有人继续在风里送一盒药。创造者可以缺席，账号可以沉默，价格可以涨跌，平台可以扣一块二。

但光如果还要往下传，就必须有人伸手接一下。

他回到出租屋，打开书稿，把最后一章写完。

他没有写那个女人是谁，也没有解释铁盒。只写那天北京风很大，楼道里有一盒粥和一盒药，有半句话被电话铃打断。

写完后，他把电脑合上，去看互助池表格。编号 004 的情况赵晴已经补了备注，编号 003 的单据也上传了。工具仓库有一个新 issue，说某个路段的门岗规则变了。他回复收到，明天改。

赵晴在群里问：“今晚谁跑北医三院？”

李觉发了路况。

发完以后，他又把那条新 issue 标成“待现场复核”，没有直接合并。

最后一章了，他也没有突然拥有正确答案。门岗会变，风控会变，钱会变，人也会变。他能做的只是把每一次变化记下来，让下一个人少把临时经验当成真理。

陈浩从杭州回：“你还真跑啊？”

李觉回：“嗯。”

母亲的语音又来，问他吃饭没有。

他回：“吃了。”

其实还没有。

手机弹出新订单。

四块九，二点八公里，送一份馄饨。

倒计时二十秒。

李觉穿好外卖服，摸了一下床底的铁盒，确认它还在那里。然后他拿起头盔，推车下楼。

楼道声控灯慢半拍亮起。

风从楼门口灌进来，冷得很实在。

李觉跨上车，点下接单。

车灯亮起来，照出前面一小段路。再往远处，还是黑的。

他没有等路全亮。

他骑了出去。
