# 第三十六章 开源之后的噪音

李觉的路线工具第一次被骂上骑手群，是因为一个带广告的二创版。

那天中午，麦当劳门口的骑手都贴着玻璃站。北京的风干得发硬，吹到脸上像砂纸。有人把手机举到李觉眼前，屏幕上是一个安装包链接，名字叫“极速抢单优化版”，图标还是他原来画的那只丑箭头。

下面多了两行字：智能识别高价单，自动规避差评商家。

再下面是一个贷款广告。

“这是不是你做的？”一个新骑手问。

李觉说不是。

“那别人怎么说是你授权的？”那人脸上有火，“我昨天装了，今天后台提示异常操作。你们程序员是不是都这样，出事就说不是我？”

他把后台提醒翻出来给李觉看。账号被限制接单两个小时，午高峰直接没了。更恶心的是，安装包里那个贷款广告开始给他打电话，一口一个“师傅最近缺不缺周转”。

“我今天少跑了六十多。”他说，“这不是你做的，也跟你有关。”

李觉张了张嘴，没说出来。

他第一反应是关库，删链接，公告写清楚：非官方版本与本人无关。这个念头来得很快，像平台一键封号一样干净。

赵晴蹲在车旁绑药箱，听完抬头。

“你要关可以。”她说，“但别学平台。先告诉人为什么关，怎么认，怎么退。”

李觉被这句话噎住。

手机震动。

下单人：中本聪。

备注：`btc block 775000`

客户备注只有一行：规则允许，不等于你喜欢。

再睁眼时，李觉站在一台安静的电脑前。

屏幕上是区块高度 709632。Taproot activation。没有发布会，没有敲钟，也没有人举着帽子喊口号。几个开发者在邮件列表和 GitHub 里留下简短的庆祝，像一次没有宾客的毕业。

有人说 Schnorr 签名能让多签更简洁。有人说 Taproot 会让复杂脚本看起来像普通转账。有人说这会让隐私更好，手续费更低。

没有人说，有一天会有人把像素骷髅头刻进区块。

李觉站在那些讨论旁边，忽然想起自己最初把工具开源时，也只是想让骑手少跑两公里。他没有想过有人会往里面塞贷款广告，像在干净水桶里倒半杯浑汤。

画面往后推了一年。

一个房间里，Casey Rodarmor 坐在电脑前。屏幕是黑的，终端字符一行行往上滚。他把一张粗糙的黑白像素图写进交易里，等待确认。风扇转得很低，屋里没有掌声。

十分钟后，区块确认。

一个骷髅头出现在屏幕上。

他发了一句：probably nothing。

大概没什么。

李觉看着那张小图，忽然有点想笑。很多风暴最开始都不像风暴。它们更像有人在墙上随手贴了一张纸，旁边的人说这也可以？

很快，所有人都知道这也可以。

图片、文本、JSON、代币符号，像被打开闸门的水，涌进比特币区块空间。mempool.space 的色块越堆越高，待确认交易像雨季里的积水，从屏幕底部漫到顶部。

一段 JSON 被刻进链上，就成了一种代币的出生证明。没有智能合约，没有虚拟机，也没有谁在后台审核。部署、铸造、转账，全靠链下索引器把那些小纸条一张张认出来。粗糙得像骑手群里的接龙，却真的能让人排队、抢号、转卖。

一个矿池监控屏上，手续费收入跳到比区块奖励还高。矿工群里有人发截图，配一个笑脸。

另一边，一个小额转账用户看着钱包报价，手续费比他要转的钱还贵。他关掉页面，像关掉一扇突然涨价的门。

李觉站在中间，第一次没有办法简单站队。

矿工说，这是市场。

用户说，这是拥堵。

开发者说，这是规则允许。

另一些开发者说，这是垃圾攻击。

争论声越来越高。有人要过滤铭文交易，有人反问谁有资格决定什么是垃圾。今天过滤 JPEG，明天过滤混币，后天过滤某个国家的地址。每个人都把“比特币真正的用途”握在手里，像握着一把能打开所有门的钥匙。

可门不只一扇。

李觉突然明白，开放系统最麻烦的地方不是坏人会进来，而是你不能只允许你喜欢的人进来。规则一旦允许，就会长出你想象不到的东西。你可以不喜欢它，可以过滤它，可以写更好的工具和说明，但你不能假装自己就是规则。

世界晃回北京。

订单完成页上只有一句话：别急着当管理员。

李觉回到出租屋，打开电脑。陈浩趴在沙发上看简历，听见键盘声，头也不抬。

“又修你的外卖区块链？”

“修我自己。”李觉说。

他没有关库。

他把 README 第一段改掉，写清楚唯一官方下载地址、校验方式、风险提示和退出方法。又加了一个“已知假版本”列表，谁都可以提交记录，但必须附截图和安装包哈希。他给工具加了版本白名单，默认只提醒，不替用户强制删除。

赵晴在群里帮他翻译。

“认准这个版本，别乱点别人发的安装包。看到贷款广告就删。不会校验的，发群里问，别装。”

有骑手问：“那你不能直接把假的都封了吗？”

赵晴回：“他又不是平台。”

晚上十一点，又有人转来一张截图。

截图里不是安装包，而是一个小程序课程页。标题写着：

`骑手路线优化进阶版，9.9 入群，含内部安装包和抢单参数。`

配图用的是李觉工具的旧界面，右上角还截着他 README 里的那句“免费使用”。下面一行小字却写成了：免费版只适合新手，会员版提供实时策略。

那个骑手问：

`这个会员版也是你们的吗？我看界面一样。`

李觉盯着“会员版”三个字，胸口像被什么东西顶住。

假安装包只是第一层。再往后，是有人把焦虑做成课程，把截图做成背书，把“免费”剪下来贴在收费入口旁边。工具没有被关掉，但它的信用正在被一层层拿走，像外卖箱上的贴纸被人撕下来贴到别人的车上。

他把 README 又往前挪了一段：

`本工具没有会员版、课程版、进阶参数包。`

`任何以本工具名义收费、建群、卖安装包的行为，都不是官方发布。`

写完以后，他知道这几行字挡不住所有人。

可他至少要把门牌挂回自己门上。

李觉想起赵晴那句“他又不是平台”，手停了一下。

半夜，他在 `block0_notes` 里补了一行：

开放不是把门拆了就完事。

开放是你知道门外一定会有灰、有广告、有骗子、有吵架的人，你还是不把自己变成唯一的门卫。
