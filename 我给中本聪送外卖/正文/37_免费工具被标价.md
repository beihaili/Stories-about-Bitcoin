# 第三十七章 免费工具被标价

假安装包的事还没完全压下去，李觉的路线工具又被卖成了一门课。

那天中午，赵晴把手机怼到他面前。屏幕上是一个短视频账号，头像是一张很亮的橙色海报，标题写得像打了鸡血：

`外卖大神私密路线课，三天提升有效单量。`

封面里有一张模糊的表格截图。

李觉一眼就认出来了。

那是他的路线工具。

只是截图被裁掉了左上角的开源地址，表头被换成“核心算法”。原本那行“仅供记录，不保证派单结果”被截得干干净净。视频里，一个男声压低嗓子说，只要掌握商圈隐形路线，就能避开低价单，提高系统信任分。

系统信任分。

李觉听见这五个字，差点笑出来。

平台有没有这个东西，他不知道。就算有，也不可能靠一张路线表提高。可这词太会骗人了。它不像“包赚”，太露骨；也不像“外挂”，太危险。它听起来像某种内部知识，刚好戳中所有骑手最怕的地方：自己是不是被系统看低了。

视频最后，二维码亮出来。

`原价 399，今天 199。`

赵晴骂了一句。

“我刚问了，有两个新骑手已经付款了。”

李觉把手机还给她，手心有点凉。

他以为假安装包已经够恶心。至少假安装包还算技术层面的坏，能靠校验、白名单、提醒挡一挡。可这次不一样。对方没有篡改他的工具，也没有往里面塞广告。

对方只是把免费的东西加了价格，把不确定的东西说成确定。

这更难处理。

下午，李觉送一单奶茶到写字楼。等电梯时，他又点开那个账号。评论区里有人问是不是真的有用，有人说自己跑了半个月还是低单价，有人问能不能分期。

分期买路线课。

这几个字像一块石头压在李觉心口。

他点开其中一个付款的新骑手头像，发现对方就在他们大群里，备注叫小冯。小冯刚跑众包不到一个月，昨天还在问商场货梯从哪进。

李觉给他发私信：

`你买课了？`

小冯隔了很久才回：

`嗯。`

又过一会儿：

`是不是被骗了？`

这句话里没有愤怒，只有那种已经猜到答案、但还希望别人说不是的尴尬。

李觉问他花了多少。

`199。`

`钱还能退吗？`

`他说资料已发，不退。`

李觉看着屏幕，想起自己刚开始跑单时，因为不会抢电池柜优惠，白白多花的那些钱。每一笔都不大，不够报警，不够吵架，也不够让旁人觉得你值得被同情。可这些小钱会一点点磨掉人的自尊。

晚上，他回到出租屋，打开自己的仓库。

README 第一行还是原来的：

`本工具免费使用，欢迎复制、修改、分享。`

他看了很久，终于明白这句话不够。

免费不是护身符。

一件东西免费公开，不代表别人不会拿它标价。尤其是当使用它的人足够着急，足够缺钱，足够相信“有内幕就能少吃亏”时，免费甚至会变成新的包装材料。

李觉开始改说明。

第一段改成：

`本工具永久免费。任何以本工具、截图、表格、路线数据为核心内容的收费课程、提单承诺、系统权重承诺，均与作者无关。`

第二段写：

`本工具不能提高派单权重，不能识别高价单，不能绕过平台规则，不能保证收入。它只记录已经被骑手验证过的路线、门岗和出餐经验。`

写到这里，他停了一下。

这几句太像免责声明。

可有些免责声明必须写得像墙，不能写得像花。

他又补了授权：

可以复制。

可以修改。

可以分享。

必须保留来源。

不得包装成付费课、外挂、内部资料或收益承诺。

不得暗示可以提高派单权重。

违反这些，不是“二创”，是割人。

“割人”两个字打出来时，陈浩正好从沙发上抬头。

“你这用词挺直接。”

“不直接他们看不懂。”

陈浩看了一眼屏幕：“你不怕他反过来骂你挡财路？”

李觉说：“他已经在拿别人的急赚钱了。”

“那你公开撕？”

李觉没立刻回答。

他以前可能会觉得公开撕很爽。截图、长文、证据链，一套打出去，评论区自然会站队。可他现在更清楚，真正受伤的不是那个卖课账号，是已经付款的人。你把骗子骂得越响，付款的人越像被一起挂在墙上。

他给小冯发消息：

`你愿意把付款记录和课程截图打码给我吗？不写你名字。`

小冯问：

`能退钱吗？`

李觉回：

`不保证。先把别人拦住。`

过了十分钟，小冯发来截图。

所谓课程资料，就是李觉公开文档的截图，加几句“高阶理解”。其中一页甚至把赵晴写的“午高峰别走，电梯堵，谁走谁死”改成了“系统不喜欢无效等待，高手会主动优化信任轨迹”。

李觉看得头疼。

赵晴看到这句，直接发语音：

“我写的是别被电梯耗死，他给我翻译成修仙了？”

李觉本来很气，听完却笑了一下。

笑完以后，他开始写公开说明。

标题很短：

`这份工具不收费，也不能让你多派单`

第一段说清楚：路线表来自骑手共同记录，不是内部系统，不是派单秘籍。

第二段放出免费入口和校验方式。

第三段列出收费课截图，打码，不放付款人信息。

第四段写给新骑手：

`你想多跑几单，不丢人。你想少走错路，也不丢人。但不要为“系统权重”“高价单识别”“内部路线课”这种词付钱。真正能帮你的，是你和附近骑手一点点把坑记下来。`

最后一段，他删了又改，改了又删。

他本来想写“不要相信任何捷径”。可这话太高。跑外卖的人不是不知道捷径危险，他们只是太需要少摔一次。

最后他写：

`如果你刚开始跑，先别急着买课。把钱留着买手套、雨衣、备用充电线。那些东西比我的表更有用。`

文章发出去后，骑手群很快炸了。

有人骂卖课的不要脸。

有人问能不能举报。

有人说“199 也不多，当买教训”。

小冯半天没说话。

过了很久，他发了一句：

`我不是想占便宜，我就是想快点跑明白。`

群里安静了一下。

赵晴回：

`没人说你。明天午高峰跟我跑一趟。别买课。`

李觉看着这句，忽然觉得这才是对付卖课最好的办法。

不是把所有门关上。

是让新来的人知道，门口有人会提醒一句：这边别进，里面收钱。

第二天，那个短视频账号把视频删了，又换了个标题重发：路线资料整理费，不承诺收益。

李觉没有再写长文。

他把这个账号加进“收费包装名单”，把证据保存好，又在工具首页加了一个很醒目的按钮：

`我是不是买到了假课？`

点进去只有三行：

第一，先停止付款。

第二，保存聊天和付款记录。

第三，免费版本在这里。

下午，对方竟然私信了他。

语气很客气。

`兄弟，都是出来混口饭吃。你的东西免费，我们帮你做传播，可以分成。`

下面还发来一张后台截图，播放量不低，评论也不少。对方说他们不是骗子，只是把免费资料整理成课程，用户愿意为“节省时间”付费。最后一句写得尤其顺：

`你做内容也需要变现，别太理想主义。`

李觉看着“理想主义”四个字，觉得有点荒唐。

他不是不想赚钱。房租、母亲、电池、互助池，每一样都要钱。他甚至能理解“整理资料收费”这件事本身不一定恶心。可对方卖的不是整理时间，卖的是“系统信任分”“高价单识别”“三天提单量”。

他们不是给人省时间。

他们是在给焦虑起价格。

李觉回了一句：

`你可以做自己的路线整理，不能拿我的工具承诺派单。`

对方很快回：

`不承诺不就没人买了。`

这句话干净得像刀。

它把这件事里最脏的地方直接摊开了：真正卖出去的不是整理好的路线，而是一个人急着翻身时愿意相信的那点幻想。

李觉截图保存，没有再回。

他把这段私信也写进公开说明里，但打掉了账号名。

不是为了装大度。

是因为他越来越清楚，卖课的人也不是凭空长出来的。他们知道谁急，知道谁怕，知道谁刚被平台扣过钱，知道谁会在深夜搜索“外卖怎么多接单”。他们像路边小广告一样贴在焦虑经过的地方。

如果只骂一个账号，明天还会有另一个。

所以他把说明页标题又改了一次：

`别为焦虑付费`

下面第一句写：

`这份工具解决不了收入问题，只能帮你少踩一些已经有人踩过的坑。`

这句话比“永久免费”更重要。

因为免费最多挡住价格。

挡不住幻想。

文章发出去后，有人问了一个很尖的问题：

`那你以后会不会也收费？`

李觉盯着这句看了很久。

说永远不收费很容易，也很像立人设。可服务器、域名、时间、维护都不是凭空来的。他不想把自己逼成圣人，也不想让别人觉得只要一个工具开始收费，就一定是在割人。

他回：

`以后如果有维护成本，会公开成本和用途；基础路线表不收费；任何收入承诺都不做。`

这句话不漂亮，也不适合做海报。

但它比“永远免费”更像能活下去的话。

赵晴看见后说：

“这句好，别把自己逼死。逼死了又没人维护。”

李觉笑了一下。

他以前总怕一谈钱就脏。后来发现，不谈钱也会脏。真正该防的不是钱本身，是拿别人的焦虑和误解赚钱。

小冯第二天跟赵晴跑了一趟午高峰。

回来以后，他在路线表里新增了一条：

`XX大厦北门看着近，但电动车进不去。新手别信导航。`

赵晴让他把“新手”两个字删掉。

他说为什么。

赵晴说：“不是新手才会信导航，累的时候谁都信。”

小冯把那句改成：

`累的时候也别信导航，先看门岗。`

李觉看到这条记录时，觉得比追回 199 块更重要。一个差点被收费课骗的新骑手，开始给下一个人留下免费的坑位。

晚上收车时，赵晴把小冯带到麦当劳门口。小冯脸有点红，手里拎着一杯没开封的豆浆。

“给你。”他说。

李觉没接。

小冯更尴尬了。

赵晴说：“给他干吗？给我。我带你绕了一下午。”

小冯赶紧把豆浆递给赵晴。

赵晴插上吸管，喝了一口，说：“第一条经验，别跟程序员客气。他们不缺豆浆，缺现实。”

李觉笑了。

风从路口吹过来，麦当劳玻璃上倒映着他们三个人和一排电动车。手机里，新的中本聪订单没有出现。只有一个邮件提醒，是基金方发来的，标题写得很体面：

`普通人叙事合作方案`

李觉看着那几个字，忽然觉得刚才那个 199 元路线课只是小版本。

更大的包装正在路上。

一个把焦虑卖给新骑手，另一个把新骑手的焦虑卖给更多人。

区别只是价格更高、话术更干净。

他打开 `block0_notes`，写下：

免费不会自动保护穷人。

开放也不会自动阻止坏包装。

所以门要开，牌子也要立清楚。
