# 第二十七章 闪电降临

迁移版工具发出去第三天，李觉收到一个很小的求助。

不是投资，不是采访，也不是资本方换了个马甲回来谈合作。那是一封英文邮件，语法有点硬，署名 Carlos，说自己在学院路一家咖啡店打工，周末也送单。他看见骑手群里有人转发李觉的开源表格，想把几条门岗说明翻成西班牙语，给店里两个中美洲来的同事用。

邮件最后写了一句：如果方便，能不能付一点小费。五美元也行。

五美元。

李觉盯着那个数字看了很久。它小到不值得走一次银行汇款，小到 PayPal 提现都会显得荒唐，小到很多人会顺手忽略。可对方在邮件里解释，妹妹在萨尔瓦多老家需要买一张手机流量包，家里那边用 Chivo 钱包能收。

他又补了一句：不是急病，也不是大事，只是外婆要用视频看医生，家里今晚没有流量了。

这句话比“五美元”更轻，也更重。

赵晴刚好在旁边等药单，听完只问：“五美元你们程序员也要走流程？”

李觉笑了一下。

“以前是。”

手机就在这时白了一下。

下单人：**中本聪**。

备注：`btc block 481824`

李觉看着这个高度，知道它不是五美元的答案，但可能是五美元能到的原因。

再睁眼时，先听见的是白板笔划过玻璃的声音。

旧金山的房间不大，桌上有披萨盒、咖啡杯和一堆写满通道、哈希、时间锁的草稿。两个年轻人围着白板争论，一会儿说交易延展性，一会儿说支付通道，一会儿又把线条擦掉重画。

Joseph Poon。Tadge Dryja。

他们讨论的不是怎么让比特币涨价，而是怎么让一笔小钱别被主链手续费吃掉。每一笔咖啡、每一张贴纸、每一份午餐，如果都要全世界所有节点记一遍，系统当然会慢。可如果两个人先在链上开一条通道，日常的小账在通道里更新，最后再结算回主链，世界就多了一层路。

李觉听得懂一半。

另一半像他以前看复杂架构图时的感觉：知道它难，也知道它不是故弄玄虚。

画面切到 2017 年。

SegWit 激活那一刻没有礼炮，只有区块高度跳到 481824。交易 ID 终于不再被签名轻易改写，那把卡住闪电网络的锁被打开。很多人以为这只是扩容战争的一场胜利，可在更深的地方，桥的地基已经打下去。

再往后，是三支队伍。

C 语言、Go、Scala。不同的实现，不同的性格，却要遵守同一套 BOLT 规范。米兰的会后小房间里，开发者们不谈口号，只啃消息格式、错误处理和路由细节。一个网络如果只能由一家公司写出来，就不叫网络。

李觉站在那些疲惫的工程师后面，忽然想起自己那份迁移版工具。

能搬家还不够。

还得让别人能接上。

最后的画面是一个海边小村。

El Zonte。土路、浪、卖 pupusa 的小店。一个人拿手机扫二维码，几乎没等，收款提示就响了。不是会议演示，也不是白皮书里的图。是一份不到一美元的食物，一笔几乎没有手续费的付款，一个没有银行账户的人第一次不用排队、不用填表、不用被抽走十分之一。

李觉看见那个收款的女人笑了一下。

很短。

短到不像历史时刻，像普通日子终于顺了一次。

世界一晃，咖啡店门口的外卖架重新出现在眼前。

Carlos 正在擦桌子，看见李觉回来，有点不好意思地把手机递过来。屏幕上是一个闪电收款码，金额 5000 sats。

“If it is too much trouble, forget it,” 他说。

李觉摇头。

他没有讲扩容战争，没有讲 SegWit，也没有讲 BOLT。他只是打开自己很久以前试着装过、后来嫌麻烦扔在角落里的闪电钱包，重新备份，重新确认，扫了那个码。

支付成功的提示跳出来时，Carlos 的手机几乎同时响了一下。

“到了？”赵晴凑过来问。

“到了。”Carlos 说。

他把手机举给他们看，像怕这件事不够真实。

赵晴盯着那一行数字：“几秒？”

“几秒。”

“手续费呢？”

李觉把屏幕给她看。

赵晴沉默了两秒，说：“那这玩意儿至少不是只能在文章里发光。”

李觉笑了一下。

这句话比任何赞美都准。

晚上，他把 Carlos 翻好的西班牙语门岗说明合并进仓库。提交信息很短：

`add es notes from real rider`

然后他在说明页加了一句：

`小额帮助优先走能少损耗的路，但风险和备份要说在人前。`

做完这些，他打开 `block0_notes`，写下：

现金不是因为会涨才叫现金。
能在一个人真的需要时到达，才算没有辜负那两个字。
