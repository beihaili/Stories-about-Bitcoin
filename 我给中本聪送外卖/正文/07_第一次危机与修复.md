# 第七章 第一次危机与修复

李觉第七次看见中本聪下单之前，刚被平台扣了五块钱。

那单从学院路一家咖啡店送到写字楼十八层。商家出餐慢了六分钟，门岗登记又卡了三分钟，电梯停在二十四层不下来。李觉站在电梯间，盯着手机上的倒计时一点点变红。

还剩一分二十秒。

电梯门开，里面挤满了人。

还剩四十秒。

他从安全通道往上跑，跑到十八层时喉咙里全是铁锈味。客户接过咖啡，第一句话是：“还挺快。”

手机下一秒弹出通知：

配送超时，扣款 5.00 元。

李觉站在写字楼走廊里，看着那条通知，喘了两口气，骂了一句很低的脏话。

申诉入口藏在订单详情最下面。点进去，选项一排排铺开：商家出餐慢、客户电话不通、天气原因、交通管制、其他。每一项点完都跳出同一句话：

请上传有效凭证。

什么算有效凭证，没人说。

麦当劳门口，骑手群里也在骂。一个新骑手发了三张截图，说自己因为小区门禁被扣了七块，申诉两次都失败。客服回复像复制出来的：经核实，订单存在超时情况，判责无误。

赵晴把手机屏幕划得啪啪响：“你骂它没用。它说你超时就是超时，除非你让它认账。”

“怎么认？”新骑手问。

赵晴看向李觉：“问他。他以前不是写系统的吗？”

李觉没接。

他以前写过很多线上事故复盘。接口超时，队列堆积，缓存穿透，数据库锁表。事故群里所有人都知道第一步不是骂，是止血，是定位，是补丁，是把证据留住。可轮到自己被一个更大的系统判错，他第一反应也只是骂。

晚上十一点半，陈浩推门进来，把工牌甩到桌上。

“今天又回滚。”他把便利蜂三明治扔进垃圾桶，连包装都没拆，“一群人在事故群里装死。上线前说没风险，出事了全问值班的为什么没兜住。”

李觉坐在电脑前，屏幕上还开着申诉页面。

陈浩往沙发上一瘫：“最烦的是没人写清楚。到底哪一步错了，谁确认过，怎么恢复，下一次怎么避免，全靠群消息往上翻。翻到最后，大家只记得有个人背锅。”

李觉手指停了一下。

手机就在这时候亮了。

下单人：**中本聪**。

备注：`btc block 74638`。

李觉看着那个高度，心里沉了一下。他知道这不是普通的区块。那是比特币早期最难看的伤口之一。

他点了接单。

导航蓝点原地转了两圈，屏幕白掉。

再抬头时，他站在一间昏暗的房间里。窗外天色像下午，也像傍晚。桌上两台显示器亮着，一边是区块浏览页面，一边是论坛。咖啡杯停在键盘旁，杯壁上挂着一圈浅褐色的印。

一个男人盯着屏幕，手没有动。

页面上的数字大得不正常。

184,467,440,737.09551616 BTC。

李觉第一眼甚至没数清小数点前有多少位。他只觉得那串数字像一个荒唐的笑话，硬塞进了一个本来应该严格到不能出错的系统里。

男人终于动了。他截屏，切到论坛，发帖。标题里有 `ALERT`，后面跟着 `strange transaction in block 74638`。

消息像火星落进干草。

论坛刷新得越来越快。IRC 聊天窗口里一行行字往上冲。有人问是不是显示错误，有人贴交易哈希，有人说总量上限是二千一百万，怎么会多出一千八百多亿。屏幕的光照在每个人脸上，所有话都短得像报警。

李觉站在角落里，背后的保温箱带子勒着肩膀。

他以前总觉得“不可篡改”四个字很硬，像钢。写进链里的东西不会被人改掉，没人能撤回，没人能赖账。可现在那条错误交易也写进去了。硬的东西一旦错了，比软的更麻烦。

聊天窗口忽然顿了一下。

有人发：

`satoshi is here`

房间里没有神出现。没有长袍，没有宣告。只有另一个屏幕亮起来，黑底白字，一行一行分析溢出的原因。金额范围检查缺失，构造交易绕过验证，输出值加总时出了问题。

语气冷静得像在处理一次线上事故。

随后，那个人打出一句话。

网络必须回到干净的状态。

李觉看着那行字，后背发紧。

回滚。

在他以前的工作里，回滚是很脏也很常见的词。版本错了，撤回；配置错了，恢复；数据写坏了，先止血再说。可这是比特币。它刚刚学会被人相信，刚刚买到披萨，刚刚从论坛里的数字变成现实里的东西。现在创造它的人说，必须把已经发生的那一段抹掉。

不抹，稀缺性烂在根上。
抹了，不可篡改就不再干净。

屏幕另一边，中本聪没有解释哲学。他在写补丁。

李觉看不见他的脸，只看见一只手、一个键盘、几行不断变动的代码。咖啡杯放在旁边，一点热气都没有。那几行改动小得可怜，像一张很薄的创可贴贴在一道很深的伤口上：检查金额，拒绝越界，别让不可能的数字通过。

有人下载测试。有人报告编译失败。有人重新打包。有人在论坛里催矿工升级。消息不停往上刷，语气越来越急，却不是命令。

没有人能按一个按钮强制全世界更新。

每个节点都要自己选择。

一个人发：`upgraded`

另一个人发：`mining on new version`

又有人问旧链怎么办。回复很短：等。等干净的链长过错误的链。等足够多的人把算力挪过来。等这个刚出生没多久的系统自己把伤口结住。

李觉站了很久。

他想起平台申诉页里那句“判责无误”。那也是一种链。冷冰冰，已经写进去，普通人只能看着结果往下滚。可眼前这条链，出错以后没有假装自己永远正确。有人把错误指出来，有人写补丁，有人说服别人一起换到修好的版本上。

它不完美。

它只是没装死。

桌边有一张打印坏的代码 diff，边缘被咖啡沾湿了一块。有人嫌碍事，把它揉了一下丢进纸篓。李觉弯腰捡起来，塞进口袋。

世界晃了一下。

他在学院路路边醒过来。夜风吹得外卖服贴在背上，手机屏幕亮着：

订单已完成
客户评价：⭐⭐⭐⭐⭐
客户留言：下次见。

另一条通知还压在下面：

配送超时，扣款 5.00 元。

李觉没有再骂。

他骑车回到出租屋，陈浩已经洗完澡，躺在沙发上刷短视频，笑声有一搭没一搭。李觉坐到电脑前，把今天那单重新打开。

他先截订单时间。
再截商家出餐时间。
再截给客户打电话的记录。
再把门岗登记本上的照片找出来，照片里有日期和楼栋。
最后打开地图，把从咖啡店到写字楼的路线和安全通道入口标出来。

他新建了一个文档。

标题写得很土：

`超时申诉材料模板`

第一行：不要只写“不是我的问题”。
第二行：按时间写。
第三行：每一步都配截图。
第四行：最后一句写“请求复核本单责任归属及扣款依据”。

他写完自己的，又把新骑手那三张截图要过来，帮他补了两句话。赵晴在群里看了半天，回一句：

`第二段太像律师。改短点。客服看不完。`

李觉删掉一半。

凌晨一点二十，他提交申诉。

凌晨一点四十，新骑手在群里发消息：

`退了，七块。`

又过了十分钟，李觉手机也亮了一下。

扣款已撤销。

五块钱。

不够买一份像样的夜宵，也不够抵掉他今天多跑的那几层楼。群里有人发了个大拇指，很快又被新的派单截图顶上去。

李觉把那张被揉皱的 diff 草稿摊平，夹进铁盒。铁盒里已经有几件小东西：旧纸片、宣言打印稿、别人的笔记痕迹、披萨油纸。它们都不值钱，也没有任何一个能替他改变现实。

但它们像一排很小的证据，提醒他别只在系统错的时候骂一句。

他打开 `block0_notes`，敲下一行：

完美的系统不存在。
活着的系统会留下错误，也会留下修复错误的人。
