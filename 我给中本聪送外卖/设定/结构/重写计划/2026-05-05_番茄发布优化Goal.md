# 番茄发布优化 Goal

创建时间：2026-05-05
状态：in_progress

## Goal

把《我给中本聪送外卖》从完整初稿优化到“可以尝试发布番茄小说的商业化定稿候选”。

核心方向：能火、能留住读者、能变现。优化优先级不是文学表达本身，而是开篇点击、前三章留存、每章追读、人物代入、冲突推进、历史内容小说化和番茄发布适配。

## 成功标准

- 前3章平均评分达到 9.0 左右。
- 第1章第一屏同时给出题材钩子和现实压力。
- 第2章承接第1章物件与 `btc block 0` 谜题，并提前引出隐私/代码主题。
- 第3章把“中本聪没有下单”写成缺席压力，而不是普通过渡章。
- 全书后续体检后，关键章节不得低于 8.0。
- 每章结尾都有明确追读理由。
- 历史节点不写成讲义，必须落到李觉现实选择。
- 不揭穿中本聪账号机制，不新增外挂解释。
- 最终能导出番茄发布包，并配套简介、标签、卖点。
