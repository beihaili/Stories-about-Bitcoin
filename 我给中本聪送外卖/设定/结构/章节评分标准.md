# 《我给中本聪送外卖》章节评分标准

版本：2026-04-23

用途：合并原 `content_pipeline` 五维质量评分和 `writing_studio` 六维创作评分，形成适合本小说的统一章节评估口径。

## 总原则

评分不是判断“文字好不好看”这么简单，而是判断一章是否真正服务整本书。

本书的硬核心是：

```text
现实刺点 -> 历史照面 -> 认知改写 -> 现实动作
```

如果一章没有回到现实动作，综合分最高不应超过 6.9。  
如果一章违反穿越规则、人物档案或关键史实，即使文字流畅，也必须降分。

## 评分维度

每项 1-10 分。综合分按权重加权计算。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 事实与术语准确性 `facts_terms` | 15% | 历史日期、人物关系、技术概念、比特币术语是否可靠；艺术压缩是否有边界 |
| 单章闭环 `chapter_loop` | 15% | 是否完成现实刺点、历史照面、认知改写、现实动作；章末动作是否具体 |
| 人物与叙事驱动 `narrative_drive` | 15% | 李觉是否被事件推动并做出选择；历史人物是否以行动出现，而不是被讲解 |
| 风格与可读性 `style_readability` | 15% | 句子节奏、段落长度、画面感、番茄阅读流畅度、开头钩子和结尾余味 |
| AI 味控制 `ai_control` | 10% | 是否避免口号、排比、总结腔、解释腔、概念先行和过度升华 |
| 灵魂时刻 `soul_moment` | 10% | 是否有至少一个让读者停一下的具体画面、物件、动作或反差 |
| 连续性与规则 `continuity_rules` | 10% | 是否符合穿越规则、物件规则、中本聪账号节奏、人物档案和章节职责 |
| 跨章连接与主题推进 `connection_theme` | 10% | 是否承接前章、铺垫后章；是否推进 A/B/C 三线，而不是孤立历史切片 |

综合分计算：

```text
facts_terms * 0.15
+ chapter_loop * 0.15
+ narrative_drive * 0.15
+ style_readability * 0.15
+ ai_control * 0.10
+ soul_moment * 0.10
+ continuity_rules * 0.10
+ connection_theme * 0.10
```

## 分数校准

| 分数段 | 含义 | 处理建议 |
|---|---|---|
| 9.0-10 | 出版级强章 | 只做错字、事实和局部节奏校验 |
| 8.0-8.9 | 可用强章 | 小修即可进入下一章 |
| 7.0-7.9 | 合格章 | 保留主体，但应按最弱维度精修 |
| 6.0-6.9 | 边缘章 | 需要重修现实动作、结构闭环或事实边界 |
| 5.0-5.9 | 问题章 | 局部重写，尤其是现实线和人物行动 |
| 1.0-4.9 | 不可用 | 重新做章节合同和 scene beats |

## 硬性降分规则

- 没有“回来后的具体动作”：综合分封顶 6.9。
- 李觉只围观历史，没有在现实里改变行为：`chapter_loop` 和 `narrative_drive` 均不得高于 6。
- 历史照面变成讲义或传记摘要：`narrative_drive`、`style_readability` 均应扣分。
- 出现未解释的穿越能力、违规带回物件、改变历史的大动作：`continuity_rules` 不得高于 5。
- 事实艺术压缩没有在锚点或审稿里说明：`facts_terms` 不得高于 7。
- 章末用口号替代动作：`ai_control` 和 `chapter_loop` 均应扣分。

## 标准输出格式

单章评分建议输出：

```json
{
  "chapter": "01_中本聪下单了.md",
  "scores": {
    "facts_terms": 8,
    "chapter_loop": 8,
    "narrative_drive": 8,
    "style_readability": 8,
    "ai_control": 8,
    "soul_moment": 8,
    "continuity_rules": 8,
    "connection_theme": 8
  },
  "weighted_avg": 8.0,
  "verdict": "pass",
  "strongest": "最强维度",
  "weakest": "最弱维度",
  "strengths": ["2-3条"],
  "risks": ["2-3条"],
  "revision_priority": "下一步最该修什么"
}
```

批量评分报告建议包含：

- 总表；
- 每章最强点；
- 每章最弱点；
- 低于 7.0 的章节重修建议；
- 高于 8.0 但事实有压缩的章节，列入史料复核清单。
