## 文件规范

每个文件有 YAML frontmatter + Markdown 正文。frontmatter 字段见 spec 第七节。

## 待建清单（后续章节推进时增量建）

- 人物：出场次数 ≥ 3 次的角色建档
- 物件：后续带回物件建档（下一个编号 03，非每章必带）
- 暗线：李觉认知成长弧、陈浩被裁炸点、母亲扭结
- 历史锚点：每章对应的历史节点（04、05…）
- 结构：连送章细纲 / 断联期现实章细纲
- 章节流程：从 06 章起继续补齐合同、scene beats、独立审稿，不再直接跳正文

## 物件回收提醒

每写完 5 章（05、10、15…），扫描 `物件/` 下所有 frontmatter 里 `实际回收章节: 待定` 的条目，确认是否有遗忘。
