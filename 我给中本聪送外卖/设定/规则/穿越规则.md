# 穿越规则

## 硬规则（A派，不可违反）

1. **触发**：美团下单人"中本聪"，备注 `btc block N`（N 的规则见下文"Block 号编号规则"）
2. **进入**：李觉骑车前往订单地址，导航打转 → 屏幕白 → 抬头发现换了时空
3. **结束**：穿越段结束即订单完成，李觉在原地或路边醒来，手机收到"订单已完成"推送
4. **现实时长**：穿越期间现实时间基本冻结（醒来时现实只过了几分钟）
5. **历史时长**：每次穿越在历史中停留 30 分钟–2 小时，少数关键节点可拉到半天
6. **参与度**：B 类参与。李觉可以搭话、旁观、近距离观察，但**不能改变任何历史走向**，也**不能告诉历史人物未来**
7. **物件**：每次穿越可以带回**一件贴身小物件**（能装进口袋或保温箱）。
   - **合规性**：物件必须是**遗失品、被丢弃物、或当事人主动弃置的副本**
   - 不能带走会改变历史叙事的原件（违者按本节"代价"处理）
   - 示例：01 章哈耶克从书里掉出的纸片（遗失品，合规）；02 章从咖啡馆"SCRATCH"废纸堆里拿走的一页宣言打印稿副本（被弃置副本，合规）

## 软规则（B派，留白）

- 中本聪账号本身的机制不解释：何时下单、为何选中李觉、对方到底是谁/是什么，全书不给出官方说明
- 穿越是否真实留一丝暧昧：所有人都当成是李觉的幻觉，只有物件是他带回来的硬证据

## 代价（中代价，断联戒断）

违反硬规则（特别是第 6、7 条）会触发惩罚：

- **短期**：当次穿越提前结束，物件带不回来
- **中期**：中本聪账号沉默数章不再下单

### 断联章落点

**13-16 章之间，连续 2-3 章**：

- **触发**：原书第 13 章（《生态萌芽》）末尾，李觉违反硬规则。候选违规：试图警告某位早期矿工远离 Mt.Gox，或贪心多带一件物件
- **断联章**：对应原书 14-15 章（《塞浦路斯时刻》《华盛顿的审视》）的位置做成纯现实章，可拆成 2-3 个现实独立章
- **恢复**：原书第 16 章（《中国政策过山车》）接单。李觉"带着觉醒后的眼睛"第一次回看中国市场

（具体章节编号以小说实际为准，13-16 区间锚点保持不变）

### 断联期的戒断反应

李觉在现实里会出现心理戒断：焦虑、反复刷手机、对外卖界面异常敏感。他开始意识到自己已经**依赖那个"看见世界的窗口"**。这是他从懵懂期→动摇期的核心心理支点。

断联结束、中本聪再次下单那一刻，李觉接单的动作会带着完全不同的情感重量——不再是四块五配送费，是一种被归还的视野。

## 穿越频率与节奏

### 基础节奏

大多数章节单章单穿，每章一个历史节点。

### 关键节点加厚（三阶段对称）

| 节点 | 连送数 | 阶段 | 节奏 |
|---|---|---|---|
| 08 中本聪消失 | 2 | 懵懂期尾声 | 中本聪最后几周活动 → 社区接棒。李觉失去一个他还没真正认识的人 |

## Block 号编号规则

三段式，对应小说三个叙事阶段。

### 前传章节（所有比特币白皮书之前的章节）

**统一备注 `btc block 0`。**

- block 0 在全书前期**不是字面意义的比特币创世区块**，而是"比特币之前的一切"的通用暗号
- 李觉第一次看到会想起"比特币创世区块"这个字面联想（01 章成稿里他就是这么理解的）
- 读到第三、四次"咦怎么又是 block 0"时，他和读者同时开始困惑——这是小爽点，也是为白皮书章的"反转"蓄势

### 白皮书过渡章

**中本聪账号静默**。这一章没有穿越订单，李觉在现实里意外刷到比特币新闻/邮件组截图，第一次从"窗外"看到这件事——像一个普通人。

静默本身就是信息：账号用"缺席"宣告"我已降临"。契合中本聪现实中的隐身气质。

### 正篇章节（比特币实存之后）

**`btc block N`，N 是接近真实的 block 高度**。

- 精度 round 到千位（如 `btc block 287000`、`btc block 824000`）
- 每章对应的真实高度以对应 `历史锚点/NN_*.md` 里的考证为准
- 从"block 0 的暧昧"到"真实高度"的跨越，象征李觉从谜题里走进现实世界

### 连送章后缀

同一事件的连送章用字母后缀区分：
- 17 章 Mt.Gox 崩塌连送 3 章 → `btc block 287000a` / `287000b` / `287000c`
- 08 章中本聪消失连送 2 章 → 同样规则
- 33 章 ETF 通过连送 2 章 → 同样规则

### 断联期

账号不发任何订单。订单列表里连"中本聪"这个客户名都不出现。这本身是信息。

### 尾声的呼应

全书最后一章，账号备注回到 `btc block 0`——但这次读者和李觉都已经明白这三个字符真正的意思。
